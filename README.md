### Build it yourself

**Requirements:** Android Studio (Ladybug 2024.2.1+), JDK 17, Android SDK API 34+.

```bash
git clone https://github.com/kurupdevs/KuruBeats.git
cd KuruBeats
# submodules are required
git submodule update --init --recursive
./gradlew assembleGmsRelease
```

The APK lands in `app/build/outputs/apk/gms/release/`.

> [!WARNING]
> Only download KuruBeats from the link above. We are not responsible for APKs from other sources.
